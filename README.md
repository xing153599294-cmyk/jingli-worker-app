# jingli-worker-app · 晶鲤焕新家 工人端原型

基于《劳务服务商平台产品功能架构与系统设计规划》实现的**工人端**可交互原型，纯前端 SPA，无需构建，直接打开 `index.html` 即可运行。

## 功能覆盖

| 模块 | 内容 |
|---|---|
| 工作台 | 今日待办（指派确认倒计时 / 复训签到提醒）、快捷入口、平台公告 |
| 抢单大厅 | 120 分钟抢单窗口、倒计时、鲁班币强抢（−50 枚）、拒绝指派自动回池 |
| 我的订单 | 全部 / 待确认 / 进行中 / 待验收 / 已完成 筛选 |
| 订单详情 | 服务商指派 120 分钟确认时限、施工节点逐项拍照上传、全部节点完成发起验收、工期延长申请（不加价）、验收评分展示、竖版流程记录 |
| 钱包 | 鲁班币余额与收支明细、服务费结算单（订单金额 × 工种费率） |
| 我的 | 档案五要素（实名 / 证书 / 保险 / 主副区域）、准入四阶段培训、周度复训签到、四维评分与排名 |

## 演示数据

首次打开自动写入种子数据（localStorage），可在「我的 → 重置演示数据」一键还原。

- 待确认指派单 ×1（47 分钟倒计时）
- 可抢订单 ×2（含热门单）
- 施工中 / 已接单 / 待验收 / 已完成（含评分）各若干
