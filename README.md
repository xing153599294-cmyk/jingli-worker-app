# jingli-worker-app · 晶鲤焕新家 产业工人端原型

按「产业工人」App 设计稿（59 屏）整体改版的可交互原型，纯前端 SPA，无需构建，打开 `index.html` 即可运行。

## 信息架构（底部四 Tab）

| Tab | 内容 |
|---|---|
| 首页 | 品牌横幅、公告卡片（更多→公告列表/详情）、快捷入口（整改/课堂/评级/买工具）、新项目通知条（→消息） |
| 接单 | 可接单 / 已接单 双 Tab；接单详情：项目信息 + 工序清单（工程量×单价）+ 接单 / 施工安排 |
| 施工中 | 本月周条 + 排期卡片（节点 / 逾期标记）；浮动按钮进施工安排日历（已安排 / 未安排 / 已完成，日历弹窗支持取消与调整安排）；项目详情四页签：施工节点 / 图纸 / 物料配送 / 结算记录；节点详情：验收标准、照片上传、说明、语音、发布日报（完成工序二次确认）；全部接单记录（待施工 / 施工中 / 结算中 / 已结算） |
| 我的 | 金色档案头（匠心值 / 等级勋章）、总收入 / 待结算 / 本年收入；我接过的所有单、我的荣誉、我的鲁班币、意见反馈 |

## 业务闭环（可演示）

- 接单 → 施工安排 → 节点日报（拍照 + 语音 + 施工标准）→ 工序完成确认
- 施工安排调整（原日期 → 新日期，生成待审核记录）与调整记录详情（已退回）
- 整改单：待处理（待整改 / 已退回）→ 上传整改照片 + 备注 → 提交完成
- 课堂：学习任务（必修 / 提升）、学习记录、推荐课程、课程视频 + 评论；发布视频（积分提示）
- 评级：当前等级 / 进行中的评级 / 晋升下一等级 / 级别权益；评级说明五级表格；考试四状态（含理论 / 实操成绩）
- 成长记录（晋级徽章）、我的荣誉（奖金）
- 买工具（鲁班币商城）：分类 / 精品优选 / 商品详情 / 立即兑换（扣鲁班币二次确认）/ 我的订单（领取码复制）
