# jingli-worker-app · 晶鲤焕新家 产业工人端原型

产业工人 App 可交互原型，纯前端 SPA，打开 `index.html` 即可运行。

## 信息架构（底部四 Tab）

| Tab | 内容 |
|---|---|
| 首页 | 品牌横幅、公告卡片、快捷入口（整改 / 课堂 / 评级 / 买工具）、新项目通知条 |
| 接单 | 可接单 / 已接单；接单详情；项目信息 + 工序清单 + 接单 / 施工安排 |
| 施工中 | 本月排期卡片、施工安排日历、项目详情（施工节点 / 图纸 / 物料 / 结算）、节点日报（拍照 / 语音 / 发布） |
| 我的 | 档案头、总收入 / 待结算 / 本年收入、我接过的单、荣誉、鲁班币、意见反馈 |

## 视觉风格

- 主色：深云杉绿 `#123B33`
- 背景：浅灰 `#F5F6F7`，白卡片 + 大圆角 + 极淡阴影
- 图标：统一线性 SVG，避免 emoji
- 强调：仅金额/逾期使用克制砖红

## 演示数据

首次打开自动写入种子数据（localStorage），「我的 → 重置演示数据」一键还原。
